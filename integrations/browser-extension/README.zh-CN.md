# Memory Box Browser Bridge v0.14.0

适用于 ChatGPT Web、Kimi Web、Claude Web、Gemini Web、DeepSeek Web、豆包、腾讯元宝，以及其他普通网页聊天。

## 功能

- 选中聊天文本后右键 → **保存选中内容到 Memory Box**。
- 点击扩展 → **保存选中对话**。
- 点击扩展 → **保存当前聊天**；优先保存选区，没有选区时提取当前页面主要聊天区域。
- 扩展内直接搜索最近记忆。
- **复制恢复上下文**：把指定记忆生成 Resume Context 并复制到剪贴板。
- **恢复到当前聊天**：把 Resume Context 填入当前页面的聊天输入框；不会自动点击发送。
- 快捷键：`Alt+Shift+M` 保存当前选中的文字。

## 安装

1. 先启动本地 Memory Box，默认地址为 `http://127.0.0.1:8765/`。
2. Chrome / Edge 打开扩展管理页，并开启“开发者模式”。
3. 选择“加载已解压的扩展程序”，选择本目录。
4. 打开任意支持的 AI 网页，选中一段对话后即可保存。

## 隐私

扩展只在你主动点击、右键或按快捷键时读取当前标签页内容。记忆发送到 `127.0.0.1` 的本地 Memory Box，不默认上传云端。恢复操作只填充输入框，不自动发送。
